# Spouts-for-Harvesting-Sap-From-Tissues-Above-and-Below-Tap-Holes

The files in this repository go with the article 'Comparing Sap Harvested From Tissues Above and Below Tap Holes', which was published in the December 2026 issue of [Maple Syrup Digest](https://northamericanmaple.org/index.php/maple-syrup-digest/), a publication put out 4 times each year by the [North American Maple Syrup Council](https://northamericanmaple.org/).

To view the spout designs' .STL files, please navigate to this repository's ['maple-syrup' release](https://github.com/davidblakneymoore/Spouts-for-Harvesting-Sap-From-Tissues-Above-and-Below-Tap-Holes/releases/tag/maple-syrup).
